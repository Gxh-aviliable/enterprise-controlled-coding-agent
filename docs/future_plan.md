# Enterprise Controlled Engineering Agent 路线规划

本文档记录项目从“多用户 AI Agent 原型”向“企业内网部署的受控工程 Agent 平台”演进的方向。

## 产品目标

构建一个部署在企业内网的工程 Agent 工作台：

- 开发者通过浏览器向 Agent 分派代码阅读、修改、测试、总结任务。
- Agent 在服务器侧受控 workspace 中执行，避免个人电脑安装高权限 Agent。
- 企业可以统一管理用户、权限、模型、workspace、工具审批、审计和项目知识。

## 差异化定位

本项目不与 Claude Code、Codex、Cursor 做个人本机体验的正面对抗，而是聚焦企业治理场景：

| 维度 | 个人 Coding Agent | 本项目目标 |
|---|---|---|
| 运行位置 | 开发者本机 | 企业内网服务器 |
| 权限边界 | 依赖个人环境 | 平台统一治理 |
| 文件访问 | 本机项目目录 | 用户/项目 workspace 隔离 |
| 模型接入 | SaaS 或个人配置 | 企业私有模型/内网 endpoint |
| 安全审计 | 弱或外部平台提供 | 内置操作记录和审批基础 |
| 记忆目标 | 个人上下文 | 项目事实、团队约定、任务结果 |

## P0：安全可控的工程工作台

### Workspace 隔离

- 所有文件 API 和 Agent 工具必须限制在用户或项目 workspace 内。
- 防止路径穿越和跨用户访问。
- Web VSCode / local VSCode 打开必须指向当前用户 workspace。
- 用户 workspace 自动初始化安全的 `.vscode/settings.json`。

### 工具权限治理

- Shell、写文件、删除、移动、子 Agent、后台任务等敏感工具进入确认流。
- 后续按角色、项目、工具类型配置权限策略。
- 提供管理员可读的工具能力清单。

### 身份认证

- 邮箱登录。
- JWT access/refresh token。
- 忘记密码支持 SMTP；开发模式下验证码写后端日志。

## P1：工程任务闭环

### Git 集成

- Agent 修改后展示 diff。
- 支持创建分支、提交、推送和 PR。
- 危险 Git 操作需要确认。

### 测试与构建

- 支持项目级测试命令模板。
- Agent 完成任务前自动运行相关测试。
- 记录测试结果到任务摘要。

### 代码评审

- Agent 生成改动说明。
- 支持按文件查看修改原因、风险和验证结果。
- 未来可接入企业代码评审平台。

## P2：企业工程记忆

当前长期记忆已经接入 Chroma，但写入质量需要重构。目标是从“聊天摘要”升级为工程知识：

### 记忆分类

- 用户画像：编辑器偏好、交互偏好、确认习惯。
- 项目事实：启动方式、目录约定、架构边界、部署流程。
- 任务结果：完成了什么、改了哪些文件、验证了什么。
- 决策记录：为什么采用某个方案，谁确认过。

### 写入质量门

以下内容默认不进入长期记忆：

- 闲聊、自我介绍、一次性问答。
- 当前目录列表、工具输出原文、临时日志。
- “我不知道/不确定”的回答。
- 无法复用的中间过程。

### 检索策略

- Agent 启动时只注入高置信度、与当前任务相关的记忆。
- `search_memory` 用于主动查询项目事实和历史任务。
- Memory UI 按类型、项目、重要性和来源展示。

## P3：审计与合规

- 记录每次工具调用：用户、session、工具名、参数摘要、结果摘要、耗时、审批状态。
- 记录文件变更：路径、diff、操作来源、验证结果。
- 支持管理员查询、导出和按项目过滤。
- 对高危操作提供二次确认和审批记录。

## P4：企业集成

- 私有模型接入：OpenAI-compatible endpoint、Qwen、DeepSeek、GLM、内部网关。
- Git 服务：GitHub Enterprise、GitLab、Gitea。
- CI/CD：Jenkins、GitLab CI、GitHub Actions 企业版。
- 知识库：Confluence、内部 Markdown 文档、接口文档。
- 工单系统：Jira、禅道、飞书/企业微信机器人。

## 当前优先级

| 优先级 | 方向 | 说明 |
|---|---|---|
| P0 | workspace 与工具权限 | 企业安全底座 |
| P0 | 会话、文件、VSCode 隔离 | 防止跨用户访问 |
| P1 | Git/diff/测试闭环 | 让 Agent 真正完成工程任务 |
| P1 | 记忆写入质量门 | 避免长期记忆污染 |
| P2 | 审计日志 | 企业采用的关键能力 |
| P3 | 外部系统集成 | 从原型走向平台 |
