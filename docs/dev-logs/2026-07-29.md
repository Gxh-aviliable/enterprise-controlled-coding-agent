### 15:03 - 明确 RedisSaver、HITL、Stop 与通用暂停的边界

- 修改内容：
  - 在 README 首页状态机附近增加显著警告：当前已经实现的是
    RedisSaver 支撑的 HITL interrupt/resume，红色 Stop 按钮执行的是不可恢复取消，
    通用的用户 Pause/Resume 尚未实现。
  - 在架构文档和后端精读指南中增加目标协议：Redis 持久化
    `pause_requested`、节点安全边界检查、`paused` 状态、checkpoint、独立
    `user_pause_gate` 中断、重新鉴权和 `Command(resume=...)`。
  - 修正暂停保存顺序：`prepare_pause` 必须先写 `paused` 并完成 checkpoint，
    下一节点才能调用 `interrupt(type="user_pause")`；不能在 interrupt 后才设置
    paused。
  - 将能力矩阵的 HITL 项改为“敏感工具中断”，并单列“用户主动暂停并继续”为
    未实现，避免把两种能力混为一谈。
- 修改原因：
  - RedisSaver 只提供图状态持久化能力，不会自动增加用户 Pause 按钮、`paused`
    状态、控制信号或通用恢复 API。
  - 当前前端 `stopGeneration()` 调用 `/chat/stream/cancel`，后端将任务收敛为
    `cancelled` 终态，因此不能宣传为可恢复暂停。
