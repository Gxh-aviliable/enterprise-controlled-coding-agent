# 2026-08-17 项目开发记录

## 修改记录

### 15:36 - SSE 工具时间线与工具卡 UI 修复

- 修改内容：
  - 将聊天区的流式状态改为有序时间线：工具开始事件会结束当前 assistant 文本片段，工具后的首个 delta 会在卡片后新建文本片段，避免后续正文回填到工具前方。
  - 为时间线条目增加稳定标识与流实例隔离；补齐缺少 `tool_start`、重复工具事件、确认后恢复、停止、取消和异常等边界处理。
  - 重做工具卡的紧凑状态 UI、键盘可访问展开按钮和执行结果区域；正文与工具统一到同一条 860px 内容轨道，并增加轻量执行时间线和响应式布局。
  - 新增时间线顺序、工具事件兜底、重复事件去重、确认恢复、工具尾部停止及工具卡可访问性测试。
- 修改原因：SSE 传输顺序正确，但前端把所有 delta 持续写入流开始前创建的同一条 assistant 消息，导致工具卡虽然按时收到，却始终显示在整段正文下方；工具卡外层同时被 flex 拉伸到聊天区全宽，与正文宽度不一致。
- 涉及文件：
  - `frontend/src/components/ChatPanel.vue`
  - `frontend/src/components/ToolCallCard.vue`
  - `frontend/tests/ChatPanel.spec.js`
  - `frontend/tests/ToolCallCard.spec.js`
